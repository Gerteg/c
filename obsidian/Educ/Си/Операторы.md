
##  Взаимодействие заголовочных .h файлов и .c 

![[Работа с многофайловой структурой.png]]
	Каждый .c файл компилируется и воспринимается компилятором отдельно от каждого. 
Соответственно, при объявлении одной переменной в main.c `int x = 0` эта переменная не будет доступна в second.c. Для разрешения этой проблемы существуют заголовочные файлы .h - в них может содержаться описание переменных и объявление функций. К примеру, 
 
`// Created by Mikhail on 10.05.2026.`  
`//`  
  
`#ifndef SECOND_H`  
`#define SECOND_H`  
  
`#endif //SECOND_H`  
  
`extern int x;`  
`void change_x(void);

Именно оператор extern нам говорит о том, что переменная x определена где-то в одном из файлов .c и по сути является глобальной. В моем случае она объявлена в файле second.c:
`//`  
`// Created by Mikhail on 10.05.2026.`  
`//`  
  
`#include "second.h"`  
`int x;`  
`void change_x(void) {`  
    `x = 5;`  
`}`

И в теле main.с проверяется значение этой переменной при прямом изменении и косвенном, при помощи функции:
`#include <stdio.h>`  
`#include "second.h"`  
  
`int main(void) {`  
    `x = 0;`  
    `printf("%d\n", x);`  
    `change_x();`  
    `printf("%d\n", x);`  
  
    `return 0;`  
`}`

Так, главное тело начинает выполнять код. Она присваивает х значение 0. А где эта переменная? Подключен заголовочный файл second.h, в котором написано extern int x. Это говорит о том компилятору, что х уже где-то объявлен. А он объявлен в second.c. С тем же успехом переменная может быть объявлена в main.c. 
## **extern**

	Оператор extern явно определяет переменную. Стандарт языка Си запрещает повторное объявление переменных (как если бы в .h файле было бы написано просто int x, тогда при написании #include в N .c файлах эта переменная будет инициализироваться N раз), этот оператор позволяет объявить ее единожды при использовании, к примеру, многофайловой структуры. Эта переменная будет доступна во всех файлах .с при инициилизации ее в одном из них.
	Когда мы пишем #include, то подключаем заголовочные .h файлы, а значит копируем их часть в наш .c файл, где мы и подключили эти заголовки. Если .c файлов несколько и в каждом из них требуется этот .h файл, то описание переменной из .h файла перейдет в два этих .c файла. Соответствено, эта переменная объявляется дважды, что может приводить либо к ошибке, либо исключению.
